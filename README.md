## 知识普及：头部姿态与手机使用检测的技术要点

*   **姿态分类的细粒度**：从正脸到后脑，头部朝向是连续变化的，模型需学习不同角度下的面部特征（如眼睛、鼻子、耳朵的可见性）。
*   **手机检测的挑战**：手机尺寸较小，可能被手部部分遮挡，且不同使用姿势（手持、贴耳、打字）形态各异，需模型具备较强的特征提取能力。
*   **遮挡问题**：头部可能被帽子、头发、口罩等遮挡，影响姿态识别，训练时需加入相关数据增强。
*   **光照与背景干扰**：车内、室内等场景光照变化大，背景复杂，建议训练时加入亮度、对比度增强。
*   **应用闭环**：检测结果可结合时序信息，判断驾驶员是否长时间分心（如持续低头看手机），触发预警或干预，服务于安全驾驶与课堂管理。

## 快速开始（代码示例）

配置文件 `data.yaml` 示例：
```yaml
train: ./dataset/images/train
val: ./dataset/images/val
nc: 7
names: ['Phone', 'Back', 'Front', 'FrontLeft', 'FrontRight', 'Left', 'Right']
```

启动 YOLOv8 训练：
```python
from ultralytics import YOLO

model = YOLO('yolov8m.pt')
model.train(
    data='data.yaml',
    epochs=100,
    imgsz=640,
    batch=16,
    device=0
)
```
